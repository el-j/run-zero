Get Started in 1 Minute Compare with ARC & act
quickstart — orbstack / zsh
# 1. Clone and initialize credentials
git clone git@github.com:el-j/local-github-runner-container.git
cd local-github-runner-container && make env

# 2. Start the Autoscaler + Verdaccio & Athens Proxy Stack
make start

# 3. Stream live runner logs
make logs

Why Developers Love RunZero

Built specifically for local developer machines, homelabs, and private GitHub accounts.

⚡

Dynamic Autoscaling

Watches your repository queue for unclaimed jobs. Spins up ephemeral containers when needed and tears them down immediately when finished (0 MB RAM at idle).

🍏

Native ARM64 + Rosetta AMD64

Run blazing-fast Apple Silicon builds natively, or execute x86_64 AMD64 Docker containers via OrbStack's Rosetta acceleration on the same MacBook.

📦

Verdaccio & Athens Caching

Built-in local proxy registries for npm, Go modules, and Docker Hub. Plus persistent volume caching for pip, uv, yarn, pnpm, and actions/setup-*.

🌐

Owner-Wide Auto-Discovery

Monitors all repositories across your personal GitHub account automatically. No tedious per-repository setup or enterprise org requirements.

🔒

Zero Kubernetes Overhead

No K8s control plane, no etcd, no Helm charts, and no cert-manager consuming 3GB of your laptop's RAM before a single job runs.

🛠️

One-Command Makefile

Effortless control with make start, make stop, make verdaccio-ui, and make cache-size.
