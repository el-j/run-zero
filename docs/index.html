Dual-Engine v2.0: Docker Containers + Dedicated Linux VMs

Run GitHub Actions Locally.
Zero Cloud Minutes. Zero K8s Bloat.

The lightweight, autoscaling GitHub Actions runner fleet for your workstation. Choose ultra-fast Docker containers (~0.3s) for rapid unit tests or dedicated Linux Virtual Machines (OrbStack, WSL2, Multipass) for browser E2E, Lighthouse, and full systemd isolation.

Get Started in 1 Minute Explore Documentation →
quickstart — local runner fleet 
# 1. Clone repo & launch interactive setup wizard
git clone git@github.com:el-j/run-zero.git
cd run-zero && make env

# 2. Start Autoscaler + Verdaccio & Athens Proxies
make start

# 3. Stream real-time runner logs
make logs

Engineered for High-Performance CI

Built specifically for local developer workstations, Apple Silicon MacBooks, and homelabs.

⚡

Dual-Engine Fleet

Execute jobs in ultra-fast Docker containers (~0.3s boot, ~20MB RAM) or dedicated Linux VMs (OrbStack / WSL2) with full systemd and unconfined Chrome sandboxing.

🧠

Hybrid Auto-Routing

RunZero automatically detects workflow labels like browser, e2e, lighthouse, or systemd and routes them to dedicated VMs while keeping standard unit tests in fast containers.

🍏

Native ARM64 + Rosetta AMD64

Run blazing-fast Apple Silicon builds natively, or execute x86_64 AMD64 Docker containers via OrbStack's Rosetta acceleration on the same MacBook without configuration changes.

📦

Verdaccio & Athens Caching

Built-in local proxy registries for npm, Go modules, and Docker Hub. Plus persistent volume caching for pip, uv, yarn, pnpm, and actions/setup-*.

🌐

Adaptive Rate-Limiting

Smart discovery filters to active repositories and real-time GitHub API header tracking to guarantee you stay well below the 5,000 req/hr ceiling.

🔒

Zero Kubernetes Overhead

No K8s control plane, no etcd, no Helm charts, and no cert-manager consuming 3GB of your laptop's RAM before a single job runs.

🛡️

100% Mutation & Unit Tested

Rock-solid codebase with 68 comprehensive tests, 0 Flake8 warnings, 100% Mypy static type safety, and Mutmut mutation testing.

🟢

Dynamic NVM & .NET 8 Pre-baked

Zero wait time: pre-installed Node.js 20 LTS, 22 LTS, 24 Current, .NET SDK 8.0, Git LFS, PostgreSQL client, and Google Chrome.

Hybrid Auto-Routing in Action

RunZero automatically inspects workflow labels and executes on the optimal backend without cluster switching.

Standard Builds & Unit Tests 🐳 Ephemeral Docker (~0.3s) 
jobs:
  unit-test:
    runs-on: [ self-hosted, local ]
    steps:
      - uses: actions/checkout@v7
      - run: npm test

# ⚡ Instant ~0.3s start, 20MB RAM idle overhead
Browser E2E, Lighthouse & Systemd 💻 Dedicated Linux VM 
jobs:
  lighthouse-audit:
    runs-on: [ self-hosted, local, browser ]
    steps:
      - uses: actions/checkout@v7
      - run: npx lhci autorun

# 🛡️ Full systemd, unconfined Chrome & true OS isolation
